Log by name where and when users visit your blog.

**Warning:** This plugin dates from 2008 and probably no longer works on modern sites. It identifies returning visitors using the WordPress comment cookie, and modern browsers now restrict and expire cookies aggressively for privacy, so this kind of cookie-based visitor tracking is unreliable. It has not been tested with recent versions of WordPress or PHP.

== Description ==
Use the cookie left after someone leaves a comment to identify their future visits to your blog.
